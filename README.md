### 👋 Hey, I'm Anas

I'm a developer from Pakistan, and I start with the business before I touch the code. Where is the owner losing hours every week? Where do leads go cold? Once that's clear, I build whatever fixes it: a web app, an n8n workflow, or an AI agent.

- 🏢 **Now:** building websites, automations and sales tools at **Agentic Tech Automations** (Dubai, remote)
- 🧾 **Freelance:** custom software for local businesses in Multan, including a full POS system for an aluminium business
- 🎓 **Studying:** BS Computer Science at NUML Islamabad, leading a team of three on my final-year project, **Festara**
- 🤖 **How I work:** Claude Code, Cursor and v0 sit inside my daily workflow. I use them to move faster on the parts that don't need my judgement
- 💬 **Ask me about:** WhatsApp bots, lead follow-up automation, Next.js + Supabase apps

### 🛠️ What I've built

| | Project | What it fixed |
|:-:|---|---|
| 🖼️ | **Frame Club** | Orders were coming in through Instagram DMs one by one. Built a proper storefront so customers can order on their own |
| 🧾 | **Aluminium POS** | Billing and records lived on paper. Built a complete point-of-sale system for the shop |
| 🏠 | **Real estate lead nurture** | Daily n8n run: OpenAI scores each lead hot, warm or cold, then WhatsApp outreach goes out and Airtable stays updated |
| 🩺 | **Clinic WhatsApp receptionist** | AI agent on WhatsApp that routes patients to booking, calendar and patient-record flows |
| 🔔 | **Renewal reminders** | Checks the sheet on a schedule and sends Gmail + WhatsApp reminders before a subscription lapses |
| 🏋️ | **Gym trial-lead flow** | Form sign-up goes straight to WhatsApp, then into a booking or a follow-up sequence |
| 🤖 | **Kaizen Bot** | Slack agent for a real estate team: searches leads and properties, and asks a follow-up question instead of guessing. Vercel Chat SDK |
| 💬 | **Portfolio concierge** | Started in OpenAI Agent Builder, now runs on ChatKit on my portfolio |
| 🎉 | **Festara** (FYP) | Event planning for groups: guests, RSVPs, shared budgets and tasks in one place |
